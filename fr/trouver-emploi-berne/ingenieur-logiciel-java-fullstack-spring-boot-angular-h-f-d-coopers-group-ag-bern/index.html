Description complète

Pour notre client de l'industrie de la logistique à Berne, nous recherchons un:n expérimenté:n, motivé:n et ouvert d'esprit:n Java Fullstack Software Engineer (Spring Boot / Angular).

Dans ce projet, vous travaillerez sur le développement d'une solution logicielle moderne et évolutive pour la planification de parcours basée sur les données et l'optimisation de processus logistiques complexes. Avec une équipe interdisciplinaire Scrum DevOps, vous concevrez un nouveau paysage système basé sur une architecture microservice et utiliserez les technologies modernes et l'apprentissage machine pour permettre des solutions de planification efficaces et fiables.

Vos tâches

  • Développement et développement d'applications Java modernes dans une architecture de microservice
  • Conception et mise en œuvre de services backend avec Java, Spring et Spring Boot
  • Développement et intégration de composants frontend avec Angular
  • Mise en œuvre et connexion des API RESTful ainsi que la documentation en utilisant Swagger
  • Utilisation d'Apache Kafka pour la communication événementielle entre microservices
  • Conteneurisation et fonctionnement des applications avec Docker et Kubernetes
  • Participation au développement de solutions d'optimisation basées sur les données en conjonction avec l'apprentissage automatique
  • Assurer une qualité de code élevée au moyen de tests unitaires, d'examens de code et de normes de développement établies
  • Participation active à une équipe interdisciplinaire Scrum DevOps et responsabilité conjointe pour atteindre les objectifs du sprint
  • Coopération étroite avec les développeurs de logiciels, les ingénieurs d'apprentissage automatique, les analystes d'affaires et les spécialistes des UX
  • Échange continu de connaissances et participation aux solutions techniques et aux décisions architecturales

Votre profil

  • Diplôme d'informatique, de génie logiciel ou de qualification comparable obtenu grâce à une expérience pratique
  • Au moins 3 ans d'expérience dans le développement de logiciels Java
  • Connaissance approfondie de Java, Spring et Spring Boot
  • Expérience pratique avec Angular et le développement d'applications web modernes
  • Bonne connaissance d'Apache Kafka et la construction et le fonctionnement des architectures de microservices
  • Expérience avec les API et les Swaggers RESTful
  • Connaissance de Docker et Kubernetes ainsi que des environnements DevOps modernes
  • Normes de qualité élevées pour le développement de logiciels, en particulier code propre, essais unitaires et révisions de code
  • Expérience pratique avec les méthodes de développement agile et Scrum
  • Méthode de travail indépendante, structurée et axée sur les solutions, ainsi qu'un solide travail d'équipe
  • Très bonne connaissance de l'allemand et de l'anglais en paroles et en écriture
